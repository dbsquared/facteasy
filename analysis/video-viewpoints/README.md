# 视频观点切分与广告识别 — 示例分析（FactEasy 能力演示）

> 本目录是 **FactEasy**（面向病毒式传播视频 / Vlog / 播客的事实核查平台）的能力示例：
> 对一条知识类视频 **半自动地** ① 按语义切分每个观点并标注时间区间；② 扫描并定位插入广告。

## 来源视频

- **平台 / BV 号**：B 站 `BV1mQuC6fEFz`
- **标题**：《蒋介石明明是名中正字介石，为何大陆会普遍称他蒋介石？》
- **时长**：20:13
- **性质**：知识讲解类 monologue（非时政谣言，但可作为"长视频结构化 + 广告识别"能力的端到端样例）

## 交付物

| 文件 | 说明 |
|------|------|
| `viewpoints.md` | 时间码 + 一句话摘要的观点清单，含广告检测结论（最便携，推荐先读） |
| `viewpoints.json` | 结构化数据（18 个观点 + 时间区间），便于二次处理 / 接入产品 |
| `build_timeline.py` | 时间轴生成脚本（输入 `viewpoints.json` + 视频路径，方法可复用） |

> （左侧 B 站播放器 + 右侧随进度联动），原先的 `timeline.html` 因依赖本地

## 分析方法

1. **音频提取 + 转写**：抽音轨 → `faster-whisper-medium`（中文，段级 + 词级时间戳）转写全文，共 462 段覆盖完整 20:13。
2. **观点切分**：基于转写稿按叙事结构做语义切分，得到 **18 个观点**，每个标注起止时间区间（时间戳取自段落边界，词级时间戳用于精确边界）。
3. **广告识别**：
   - 赞助类关键词扫描（赞助 / 广告 / 福利 / 会员 / 链接 / 三连 / 点赞 / 转发 / 优惠券 …）：**0 命中**；
   - 段间停顿 > 2.5s 检测（典型广告特征：音乐突变、口播断裂）：**无**；
   - 结论：本视频为纯知识讲解，**未检测到插入广告段**。

## 广告检测结论

**未检测到插入广告。** 全稿赞助类关键词 0 命中，全程连续口播、无音乐/主题断裂。
（若怀疑存在只走画面/音乐、不进音轨的纯视觉广告，可追加音频能量谱扫描。）

## 查看方式

- **最便携**：直接读 `viewpoints.md`，含完整时间码清单与广告结论。
- **可交互**：打开站点的 `../../pages/sync-player.html`，左侧播 B 站视频、右侧内容随进度联动，18 个观点按时间轴高亮。
- **本地生成时间轴（可选）**：`python build_timeline.py` 会基于 `viewpoints.json` 生成一份 `timeline.html`，
  它内嵌的是**本地 mp4 绝对路径**，仅供本地查看，不适用于 GitHub Pages。

## 已知限制

- **画面相关性未评估**：本分析以音频/字幕为主信息源（视频画面多为拼凑无关素材，少数观点与画面结合）。如需判断某观点片段画面是否"相关"，可抽取该时间段关键帧核验。
- **转写误识**：存在个别同音误识（如"介石"误为"介时"、"中正"误为"钟正"），观点标题/摘要已按史实校正。
- **原始媒体未入库**：源视频（134MB mp4）与提取音频（38MB wav）体积过大，未纳入本仓库，仅本地保留于 `video-fetcher` 项目。
