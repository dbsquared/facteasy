## 一、评估方法

### 1.1 来源性质三标签法（可并存）

每条观点按成分打标签，**可同时带多个**；每条论点（成立环节 / 疑点）也单独标注其所对应的成分。

| 标签 | 定义 | 核查路径 |
|---|---|---|
| **转述** | 内容可在外部权威来源中找到，作者只是复述或转译。 | 定位原始出处 → 评估该出处的权威层级 → 判断作者转述是否忠实 |
| **专属** | 这一说法、选材或措辞只见于本视频（作者独有），但仍是可证伪的事实性断言。 | 检索是否有第二来源 → 无第二来源则按「孤证」降级，只评事实真伪不评解释 |
| **原创** | 作者自行建构的解释框架、归因、价值判断，不可或难以直接证伪。 | 自行检索证据 → 检验逻辑自洽性与可证伪性 → 判断证据与结论的关联强度 |

> 一条观点可同时带有多个标签。原"兼有"一律拆为「专属 + 原创」两个标签：表示该观点既有仅见于本视频的成分，也有作者的原创阐释。每条论点（成立环节 / 疑点）另标注其对应的成分，便于定位。

> **关键原则**：**事实为真 ≠ 解释成立**。凡带「原创」成分的观点，
> 事实骨架与解释框架分开评级（如 `事实 A / 归因 C`）。

### 1.2 权威层级（Tier）

| 层级 | 含义 | 本样本中的例子 |
|---|---|---|
| **T0** | 一手史料 / 原始档案 / 典籍原文 | 《礼记》《仪礼》、唐代避讳令原文、1972 年会谈记录、唐前译经 |

| **T2** | 权威学术专著 / 核心期刊论文 / 专业考据 | 洪迈《容斋续笔》、现代史学辨伪论文、人物传记研究 |
| **T3** | 主流媒体 / 官方机构发布 | 人民网、光明网、央视网、澎湃、入境事务处表格 |
| **T4** | 百科 / 聚合类自媒体 | 百度百科、自媒体二次演绎 |

**降级规则**：同一信息若只有 T4 来源而无上层支撑，一律不下 A 评级。

### 1.3 综合评级

| 评级 | 含义 |
|---|---|
| **A** | 成立。有 T0–T2 级证据直接支撑，无实质疑点 |
| **B** | 基本成立。主干可信，但需限定条件 / 表述绝对化 / 个别细节有版本差异 |
| **C** | 部分成立。方向不错但证据强度不足、举例失当或解释属推测 |
| **D** | 不成立 / 证据不足。与证据冲突，或缺乏可验证依据 |
| **N/A** | 纯价值判断或修辞，不具真伪属性，不可证伪 |

含子观点时按**最弱环节**计分布（如 `事实 A / 归因 C` 计入 C）。

**站得住的部分**

- 观点 15 的推论逻辑无效
